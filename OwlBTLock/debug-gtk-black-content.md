# GTK 内容区不可见调试记录

状态：[OPEN]
会话：gtk-black-content

## 症状
窗口标题栏可见，主体内容区域大面积黑色，控件未正常显示，左上角存在布局异常。

## 可证伪假设
1. 根容器 `main_box` 没有获得有效分配尺寸。
2. 监控页或其父容器运行时仍处于不可见状态。
3. 监控页根容器或页面切换容器高度为零。
4. 页面未正确挂载到窗口根节点，或被错误的布局约束覆盖。
5. Wayland 下窗口显示尺寸与 GTK 子节点分配不一致。

- [ ] 添加最小运行时布局日志
- [ ] 启动并收集修复前证据
- [ ] 根据证据实施最小修复
